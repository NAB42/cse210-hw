List of Commands:

    ls                   lists all of the goals, and how complete they are

    pwd                  prints # of points accumulated on this user, and their rank

    cd                   marks goal as "Completely Done"

    touch                creates a new goal after the user follows the specified prompt

    cat                  displays the standings among all users.

    whoami               displays the current user

    su [user]            switches the user

    rm [user]            (requires root) removes specified user

    uname                shows the version

    help                 displays this menu

    exit                 quits
